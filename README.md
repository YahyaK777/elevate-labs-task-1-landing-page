# Task 1 – Responsive Landing Page (HTML & CSS)

A clean, responsive landing page for **Tidewatch**, a fictional tide and surf-conditions app, built for the Elevate Labs Web Development Internship.

## Files
- `index.html` – semantic HTML5 structure (header, main, sections, footer)
- `style.css` – all styling, layout and media queries

## What I built
- **Header** with logo and navigation links (sticky). On screens ≤ 720px the nav collapses into a hamburger menu, done with pure CSS (checkbox toggle, no JavaScript).
- **Hero section** with heading, paragraph, call-to-action button and an inline SVG tide chart.
- **Features section** using CSS Grid (4 columns → 2 → 1 as the screen shrinks).
- **Call-to-action band** and a **footer** with social links.

## Concepts used
HTML5 semantic tags, CSS3 custom properties, Flexbox (header, hero, footer), Grid (features), media queries (900px, 720px, 480px), responsive typography with `clamp()`, visible keyboard focus, and `prefers-reduced-motion`.

## How to run
1. Open the folder in VS Code.
2. Right-click `index.html` → **Open with Live Server**.
3. Resize the browser window to test the layout.
